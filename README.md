---

## Project Architecture

Rather than organizing notes by date, I group them by topic so concepts and implementations remain easy to revisit and build upon.

The repository is divided into two primary areas:

* **`/linux`** — Systems administration, shell fundamentals, utilities, process management, security, and operating system internals.
* **`/python`** — Core programming concepts, data structures, scripting, and automation projects.

Each entry is structured to cover the core concept, key learning points, and practical infrastructure use cases that connect the topic directly to networking and systems administration workflows.
