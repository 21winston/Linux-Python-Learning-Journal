### Technical Takeaways

* **The Interactive Interpreter (REPL):** Instead of just writing massive scripts right away, I can use the Python interactive prompt (`>>>`) to test logic, variables, and math in real-time. It acts as a powerful sandbox.
  
* **Numbers & Expressions:**
  Reviewed how Python handles math operations. The distinction between standard division and floor division is critical:
  * Standard Division: `1 / 2` evaluates to `0.5`
  * Floor Division: `1 // 2` evaluates to `0` (rounds down to the nearest whole number)
  * Modulo (Remainder): `10 % 3` evaluates to `1`

* **Variables & Assignment:**
  Python is dynamically typed. I don't need to declare what type of data a variable holds beforehand. 
  `x = 3` binds the integer 3 to the variable `x`.

* **Statements vs. Expressions:**
  * An *expression* is something that evaluates to a value (e.g., `2 * 2`).
  * A *statement* is an instruction that does something (e.g., `print(2 * 2)` or `x = 3`).
